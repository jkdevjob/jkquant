## 0. 이어받을 때 본 숫자 (11/13)

- 유튜브 구독 5명, 쇼츠 10편 남짓. 조회 대부분 4~135회.
- 뜬 것: "T1 또 BLG…4강전이 월요일 아침인 이유"(1천) — 많은 사람이 궁금해할 '왜?' 하나에 답. 그다음 "카톡은 무료인데, 카카오는 뭘로 돈 벌까?"(135), "반대매매 유예, 내 계좌도 자동으로 될까?"(74), "버즈가 보청기 된다는데…내 것도 될까?"(51) — 모두 **내 경우 질문**.
- 안 된 것: 젠슨 황 사임·불륜·스파이 '의혹'(7~20), 철도 총파업 예고(4), 65세 고용(6) — 의혹·예고·남의 일.
- 은퇴노트에서 확인된 것(STRATEGY 6장): 시청자가 자기 줄을 찾는 '내 칸 표'가 뉴스 해설보다 조회 중앙값 10배. 팔로워는 히트 뒤에만 늘었다.

## 1. 주제 고르기

- **(11/17 사용자) "매니악브리핑은 경제만 올리지 말고 어떤 주제든 최근 진짜 핫한 이슈 올려"** → 분야를 가리지 않는다(경제·산업·AI·생활 기술 + 사회·스포츠·연예·정치·국제·날씨·사건 등). 기준은 **'진짜 핫한가'**: 네이버 많이 본·댓글 많은 뉴스 상위, 여러 언론이 같이 다룬 것(관련 기사 수), 구글 트렌드 급상승·자동완성 새로 뜬 것, 유튜브 쇼츠 이번 주 상위(`node trends/hot-news.mjs` — 은퇴 가중치는 무시, `node trends/curious.mjs` 급상승, `node trends/scan-youtube.mjs --tag mb`).
- 고른 이슈에서 **사람들이 가장 궁금해할 질문 하나**에 확인된 숫자·사실로 답한다(GPT 시절 가장 잘된 편도 경제가 아닌 'T1 4강전이 월요일 아침인 이유' 1천 회). 내 돈·내 기기·내 일에 닿으면 더 좋지만 필수는 아니다.
- 좋은 각도: "카톡은 무료인데 카카오는 뭘로 돈 벌까?", "내 폰/내 계좌/내 요금은?", "왜 ○○일까?"(궁금증 하나에 숫자로 답).
- **하지 않는 것**(분야가 넓어져도 그대로): 실존 인물 의혹·사생활·연애·불륜·스파이 '의혹', 수사 중 사건의 범인 단정, 확인 안 된 소문·지라시, 사고 피해자 신상, 혐오·조롱, 종목 매수·매도 추천, 금융상품 추천·가입 유도·제휴 링크, 증권사·기업 보도자료 수익률 옮기기, 정치 공방 한쪽만. 은퇴노트와 같은 주제·같은 표는 피한다(겹치면 둘 중 한 채널만).
- (11/16) 은퇴노트 점검에서 적금·대출·주식 손실·증여·양도 같은 **일반 재테크·세금**은 은퇴노트 시청자에게 약했다(3초 12~19%) → 이런 주제는 매니악이 맡는다(은퇴노트는 연금·노후 돈만).
- 숫자는 원문 기사 2곳 이상 또는 공식 자료·직접 계산. 확인 못 한 숫자·인용 금지. 지어낸 사연 금지.

## 2. 영상 형식 (25~35초, 9:16)

- 렌더: `node make-note.mjs --config reel/queue/mb/issues/<날짜><a|b>.note.json` — 설정에 **`"skin": "brief"`**(**v2, 11/19 사용자 "부엉이도 남색도 맘에 안 들어 전체적으로 다 바꿔"**: 주황 배경 + 흰 보드, 검정 고딕, 주황(#ff4d1f)·노랑(#ffd60a) 강조, 띠는 검정 + 노랑 핵심어, 연필 소리 작게). 은퇴노트 노트 설정과 같은 문법(text·circle·sticky·@시각 참조).
- 목소리: `ko-KR-SunHiNeural`, rate "+8%" (은퇴노트 현수 목소리와 구분).
- 테이프: `"매니악 브리핑 #N"` (color 무시, 검정 알약 모양).
- 흐름: ① 표지(첫 줄 = 내 경우 질문 + 숫자) → ② 배경 한 줄(뉴스) → ③ **핵심 숫자 표 3~5줄**(내 칸을 찾을 수 있게) → ④ "사실 / 해석 / 전망" 구분 한 줄씩(채널 약속) → ⑤ 확인할 것 → 팔로우 요청.
- **표지는 '표지 v3'**(ISSUE_GUIDE 3-4, 11/17~): 위 두 줄 제목(흰 글자 + 호박색 결론 숫자) + 핵심 숫자 표 전체를 처음부터 보이게(`sheetCover({skin:"mb", …})`). '??' 가림·큰 물음표 금지. 예시 `reel/queue/mb/issues/2026-11-17b.note.json`.
- **(11/19) 제목 공식 v4**(ISSUE_GUIDE 3-4 6번, 잘되는 채널 연구 REFERENCES 11/19): 표지 1줄은 주제 이름이 아니라 **주장·명령·반전·'내 위치'**("~하면 손해", "~말고 이때", "~인 이유", "A VS B", "40대 평균 월급은"). 2줄은 결론 숫자. 숫자로 뒷받침되는 반전만, 과장 금지.
- 뉴스 대사 동안 화면이 비지 않게 핵심 한 줄을 큰 글씨로.
- **고정 제목 띠**(ISSUE_GUIDE 3-5): 11/14 주는 모든 편에 `"band"` 를 넣는다(분야 인기 쇼츠 6편 중 5편이 이 틀). 큐 항목에 `"exp":"band"`. 종이 y 1450 아래는 비운다.
- 저장용 표: 분야 인기 쇼츠에 "1990 vs 2026 생활물가 14줄" 같은 **긴 비교표 한 장**이 있었다(저장·공유용). 숫자가 많은 주제면 마지막 장을 "저장해 두세요" 표로(2곳 이상 확인한 숫자만).

## 2-1. 카드뉴스(캐러셀) — 11/19 사용자 "매니악브리핑도 카드뉴스 만들어"

- 인스타 카드뉴스 6장(1080×1350 JPEG): `node make-cards.mjs --config queue/mb/cards/<id>.cards.json` — 설정 `"brand":"mb"`(흰 카드 + 위 주황 띠, 검정 표 머리, 노랑 강조), 장 종류 cover(tiles 4칸·bars·box)·table·list·cta. 예시 `queue/mb/cards/m20261120b.cards.json`.
- 큐 항목 `kind:"carousel"`, `images:[…6장]`, `file`(첫 장), `exp:"carousel"`. 업로더가 사진 묶음으로 올린다(유튜브는 건너뜀).
- 일정: **금요일 20:30 = '이번 주 핫이슈 숫자 정리'**(그 주 매니악 편 숫자 묶음, 첫 편 m20261120b) + 다른 날은 20:30 칸에서 하루 걸러 '한 이슈 정리' 카드뉴스를 영상 대신 시험(저장·공유·팔로우 비교). 매일 루틴은 그날 b 가 이미 있으면 a 만 만든다.
- 숫자는 영상과 같은 규칙(2곳 이상 확인·직접 계산). 장마다 표 4~6줄, 넘침 경고(⚠)가 없을 때까지 줄인다.
- **마스코트 '매니'**(주황 스카프에 마이크 든 캐러멜색 **곰 기자**, `assets/mascot-mb.svg` — 11/19 부엉이 → 고양이 → 사용자 "곰으로 해봐"로 곰. 베어마켓(약세장)의 곰 — '하락장에도 정신 차리게 해 주는 곰') — 영상 표지(sheetCover 자동)·끝 장면(`mascotEnd`)·카드뉴스(배지·말풍선)에 넣는다(ISSUE_GUIDE 3-4 8번).
- (11/19 사용자 참고 계정) 굵은 글씨 꼴(`"style":"bold"`, 검정 + 주황 강조)도 쓴다 — `hero` 의 `visual:{kind:"big", big:"+83%", cap:"…"}`(굵은 테두리 큰 숫자) + 아래 큰 글씨 제목. '경제 정보 계정(36만)'처럼 **매일 같은 이름의 시리즈**(예: "11월 ○일 아침, 꼭 알아야 할 숫자 3개")를 시험할 수 있다 — 인물 사진·합성·종목 추천은 하지 않는다.
