# 매일 이슈 영상 제작 규칙

매일 아침(06:37 KST) 예약 작업이 이 문서를 따라 **전날 가장 큰 경제 이슈**로 영상 한 편을 만들어
발행 큐에 넣는다. 저녁 19:47 발행 작업이 인스타 릴스 + 유튜브 쇼츠로 올린다.
기준 예시: `queue/issues/2026-10-30.card.json` (미국 금리 동결, 인상 2표)

## 1. 주제 고르기

- 범위: 전날(한국 날짜) 하루 + 그 밤사이 미국 시장·발표.
- 가장 큰 것 하나. 판단 기준 — 주요 언론 2곳 이상 머리기사 / 시장 숫자가 크게 움직임 /
  40대 이상의 돈(연금·대출·예금·환율·세금·부동산·증시)에 바로 닿음.
- 지난 7일 안에 다룬 주제는 피한다(queue.json 의 `kind: "issue"` 항목 확인). 같은 사건의 큰 진전은 가능.
- 다루지 않는 것: 개별 종목 매수·매도 권유, 확인 안 된 루머가 핵심인 이슈, 정치 진영 싸움 그 자체,
  사건·사고 비극을 자극적으로 쓰는 것, Anthropic 관련 이슈(이해충돌).

## 2. 조사·검증

- 서로 다른 출처 **2곳 이상**, 가능하면 1차 자료(연준·한국은행·통계청·국세청·거래소 등) 1곳 포함.
  숫자는 기사 원문에서 직접 확인한다. 요약 도구가 준 숫자만 믿지 않는다.
- 시세는 `lib/data.mjs`(야후 데이터)로 한 번 더 맞춰 본다.
- 숫자마다 기준 날짜. 전망·추정은 "~전망", "~보도"로 밝힌다. 인용문을 지어내지 않는다.

## 3. 제목(어그로) 규칙

목표는 첫 1초에 손가락을 멈추게 하는 것. 단, **내용과 다른 제목은 쓰지 않는다**
(낚시로 느끼면 바로 넘기고 신고해서 노출이 오히려 줄어든다).

쓰는 방법
- 숫자 + 반전: "금리 동결인데 '올리자' 2표"
- 질문으로 긴장: "…12월에 또 오르나?"
- 대비: "주가는 6% 올랐는데 환율은 왜?"
- 내 돈으로 연결: "변동금리 대출 있으면 이것부터"
- 손해 회피: "모르면 최대 148만원 못 돌려받습니다"(조건이 맞는 사실일 때만)

쓰지 않는 것: "무조건", "100%", "폭락 확정", "지금 당장 사라/팔아라", 사실이 아닌 공포·과장,
특정 종목 추천, 남의 영상 제목 베끼기.

- 유튜브 제목: 40자 안팎 + 끝에 ` #Shorts`.
- 인스타 캡션 첫 줄 = 같은 훅(피드에서는 첫 줄만 보인다).
- 카드 첫 화면(키커 + 첫 두 줄)에도 같은 훅이 보이게 한다.

## 4. 영상

- 기본은 텍스트 카드(`make-card.mjs`). 테마 `navy`(시장·금리·숫자) / `cream`(생활·연금·공감).
- 키커 12자 이내, 큰 줄 10자 이내(넘치면 줄을 나눈다), `~작은 줄` 16자 이내, 줄 5~6개.
- 강조 `**…**` 1~2개. `note` 에 기준·출처 1~2줄. 슬로건은 navy "감이 아니라, 숫자로" / cream "늦지 않았습니다".
  핸들 `@retire.note`, 길이 12~13초.
- 시세 이슈는 데이터 릴스(`make-reel.mjs`, 적립식 결과 등)를 써도 된다.
- 렌더 전에 `--preview` 로 마지막 장면 PNG를 보고 글자 넘침·어색한 줄바꿈을 고친다.

## 5. 캡션

훅 한 줄 → 빈 줄 → 사실 3~4개(`· `로 시작, 날짜·숫자 포함) → 빈 줄 →
"내 돈에는?" 1~2줄(일반 원칙, 투자 권유 아님) → `출처: …` → `정보 제공 목적 · 투자 권유 아님` →
해시태그 5~8개(`#은퇴노트` 포함). 꺾쇠(`< >`)는 쓰지 않는다(유튜브 거절).

## 6. 파일·큐

- 카드 설정: `reel/queue/issues/YYYY-MM-DD.card.json` / 영상: `reel/queue/issues/YYYY-MM-DD_<영문-slug>.mp4`
- `queue.json` 의 `items` 에 추가:
  `{"id":"iYYYYMMDD","kind":"issue","date":"YYYY-MM-DD","file":"queue/issues/….mp4","caption":"…","yt_title":"… #Shorts","tags":[…],"sources":[…]}`
- `date` 는 발행일(= 만드는 날). 이슈 영상은 **그날만** 올라가고 지나면 건너뛴다.
  이슈 영상이 없는 날에는 예비 영상(`kind` 없는 항목, 예: week2)이 대신 나간다.
- 점검: `node publish-social.mjs --dry --id iYYYYMMDD` → 커밋·푸시
  (브랜치 `claude/instagram-reel-video-creation-wl16ee`, main 금지). 발행 작업은 푸시된 최신 커밋을 쓴다.

## 7. 명령

```
cd reel
export PLAYWRIGHT_CHROMIUM_EXECUTABLE=/opt/pw-browsers/chromium-1194/chrome-linux/chrome
node make-card.mjs --config queue/issues/2026-10-30.card.json --preview   # PNG 확인
node make-card.mjs --config queue/issues/2026-10-30.card.json             # mp4
node publish-social.mjs --dry --id i20261030
```
