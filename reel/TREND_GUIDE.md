# 매일 동향 분석 영상 규칙

매일 아침 작업에서 **같은 분야(은퇴·노후·연금)에서 지금 조회수가 잘 나오는 영상**을 모아 보고,
잘 먹히는 주제와 제목 구조를 가져와 **우리 형식·우리 숫자로 새로** 만든다. 12:30 게시.
(전날 이슈 영상은 `ISSUE_GUIDE.md` 대로 20:00 게시 — 하루 2편)
기준 예시: `queue/issues/2026-10-30-t.note.json` ("국민연금 60세 vs 70세, 받는 돈 2배? 본전 나이는")

## 1. 수집

```
cd reel && node trends/scan-youtube.mjs      # → trends/YYYY-MM-DD.md / .json
```

- 유튜브 공개 검색 결과만 쓴다(키워드 14개 × 이번 달 쇼츠·이번 주 쇼츠·이번 달 일반 영상 조회수순).
- 인스타는 공개 데이터를 가져올 길이 없어서, Metricool 에 경쟁 계정을 넣어 두면 그 릴스도 같이 본다
  (`getAnalyticsDataByMetrics` 의 `IGCR01~10` — 경쟁 계정이 없으면 건너뛴다).

## 1-1. 기법 학습 — 매일 다른 인기 영상 보기

```
cd reel && node trends/frames.mjs --n 6     # → trends/frames/YYYY-MM-DD/sheet.jpg (행 번호 = 목록 순서)
```

- 오늘 리포트에서 **아직 안 본** 인기 쇼츠 6편(광고 제외)의 첫 장면 + 중간 장면 3장을 한 장으로 붙인다.
  본 영상은 `trends/seen.json` 에 쌓여서 다음 날엔 다른 영상을 본다. 이미지는 커밋하지 않는다.
- sheet.jpg 를 직접 보고 기법을 적는다: 첫 장면에 무엇이 보이나(제목 띠·숫자·얼굴), 글자 크기·색, 화면이 바뀌는지/한 장으로 끝나는지,
  질문→답 구조, 끝의 행동 요청 등.
- `trends/LEARNINGS.md` 에 날짜별로 적고, 여러 날 반복해서 보이는 기법은 위쪽 표로 올린다.
- **오늘 영상(동향·이슈 둘 다)에 1~2개 적용**하고 queue.json 항목에 `"techniques": [...]` 로 남긴다.

## 2. 분석 (리포트를 읽고 메모)

- 빼고 본다: 증권사·운용사 공식 채널 광고, 특정 정치인 공격형 영상, 연예인 가십.
- 뽑을 것: ① 지금 많이 보는 **주제 3개** ② 잘 먹히는 **제목 구조 3개**(예: 숫자 비교 "60세 vs 70세", 질문 "언제 받아야 이득?",
  나이 "50대", 목록 "N가지") ③ 길이·형식(쇼츠 20~40초, 비교표·목록이 많은지).
- 최근 7일 우리 영상과 겹치는 주제는 피한다(queue.json 의 kind issue·trend 확인).

## 3. 만들기 — 베끼지 않고 더 낫게

- 주제와 제목 구조는 따라가도 되지만 **대본·화면·제목 문장·썸네일은 베끼지 않는다.** 남의 영상 클립·음악도 쓰지 않는다
  (저작권 + 유튜브·인스타의 재사용 콘텐츠 정책 → 노출 감소).
- **우리만의 각도 하나**를 꼭 더한다: 직접 계산(본전 나이, 낸 돈 vs 받는 돈, 월 얼마), 최신 제도 변경 반영, 흔한 오해 바로잡기.
- 숫자 확인·영상 형식·캡션 말투는 `ISSUE_GUIDE.md` 2·4·5번과 같다(출처 2곳 이상, 손글씨 노트, 사람 말투, 지어낸 경험 금지).
- 제목은 리포트에서 잘 된 구조를 따르되 내용과 다르면 안 된다.

## 4. 파일·큐·게시

- 노트 설정 `queue/issues/YYYY-MM-DD-t.note.json`, 영상 `queue/issues/YYYY-MM-DD_<영문-slug>.mp4`
- queue.json 항목: `{"id":"tYYYYMMDD","kind":"trend","date":"YYYY-MM-DD","file":…,"caption":…,"yt_title":…,"tags":[…],
  "sources":[…], "basis":[참고한 인기 영상 주소 2~3개], "angle":"우리만의 각도 한 줄"}`
- Metricool 예약은 `ISSUE_GUIDE.md` 6-1 과 같은 방식, 시각만 **12:30(Asia/Seoul)**.

## 5. 성과 보고 (일요일)

- Metricool 분석으로 지난주 우리 영상(유튜브·인스타) 조회수·좋아요를 모아 `trends/weekly-YYYY-MM-DD.md` 에 정리하고,
  잘 된 주제·제목 구조를 다음 주 선택에 반영한다.
