## 비교 규약

- 시초가 종료 주문은 새 버전에서 09:30의 시세 감시보다 먼저 시도한다. 09:30 이후 신규 매수는 차단한다. 09:30 가상 종료가격은 그때 이미 완료된 09:29 분봉 종가 대용이며 실제 모의계좌 체결과 구분한다. 과거/야간 v1 재구성의 09:30 분봉 종가와 합쳐 같은 버전 성과로 부르지 않는다.
- 시간 제한 없음도 **당시 손절/익절을 유지**한다. 물타기·손절 취소·손실 중 기한 연장은 하지 않는다. 익일/다일 비교는 메인 주문에 연결하지 않는다.
- 메인 원본 이벤트/서버 모의장부의 실제 진입 ID·시각·가격·버전·파라미터·비용을 고정한다. 처음 도착한 지 10분 이상 지난 진입이나 연구 수입 자료는 늦은/과거 표본으로 제외 기록한다. 결과가 나빴다는 이유로 제외하지 않는다.
- 비교자본은 국내/BTC 각 1,000만원, SOXL 각 1만달러씩 독립적이다. 시초가/데이는 3슬롯, BTC/SOXL은 1슬롯. 같은 초기 슬롯 예산과 당시 가용현금 중 작은 금액을 쓰고 손실을 외부 돈으로 보충하지 않는다. 가격 영향 비교를 위한 소수수량 모형으로, 증권사 정수수량 체결 성과가 아니다. 자본 점유로 다음 진입을 받지 못한 경우도 기록한다.
- 메인 비교행은 원본의 확정 청산을 참조한다. 나머지 행은 앱 내 전향 비교 엔진이 실제 원천 봉을 처리한다. 같은 봉의 손절/익절 충돌은 손절 우선, 장을 넘긴 갭 하락은 손절가보다 나쁜 실제 시가를 사용한다. 종가 기반 시초가는 원래처럼 종가 기반 위험 판정이다.
- 완료 봉만 쓴다. 미확정 미래 봉·누락된 종료 봉·늦은 시세를 과거 체결로 만들지 않는다. 봉/세션 시가 누락은 `unverified`, 이후 실제 누락 봉이 도착하면 경로를 이어간다. 미국 세션 종료 시각은 시세 제공자의 정규 세션 메타데이터를 사용해 조기 폐장도 구분한다.
- 종가형 연구가격은 진입 직전 완료 분봉과 15:14 분봉의 종가 대용(15:15 청산 시점에 완료)이며 관측 시각과 가격 시각을 따로 저장한다. 한투 모의주문은 14:45 매수/15:15 매도이고 체결·미체결·잔여 보유는 별도 주문 원장이다. 메인 모의투자 설정을 자동으로 켜지 않는다.
- 2026-11-09 이후 새 종가 익일시가 진입은 중단한다. 이전 버전의 이력·기존 보유의 청산/정산 경로는 보존한다. 새 종가 통계는 버전별로 분리하고 과거 15:30형과 합쳐 개선으로 주장하지 않는다.
- 모의 평가수익은 미청산 평가와 비용을 포함한다. PF는 실제 배정 가상금액을 반영한 비용 후 확정 이익/손실 합계의 비율이다. 일평균/최악일은 확인한 연속 세션 종료 평가만 사용하고 MDD는 5분 주기 관찰값(틱 단위 최대 낙폭 아님)이다. 원천 실패·미확인·첫 표본 대기는 0% 무매매와 구분한다. 이전 세션 마지막 봉 누락도 익일 관찰로 숨기지 않는다.
- 원본은 변경하지 않고 비교 기록은 별도 Durable Object에 저장한다. 거래별 키로 분리해 하나의 저장 값이 계속 커지는 것을 피한다. API/화면은 소유자 인증을 유지한다.
