# QQQ 적립 → 하락 때 QLD 로 바꾸기 — 검증 (2026-11-11)

사용자가 보낸 요약 화면의 전략:

- 상승장에서는 1배수(화면의 'IQQ' — 나스닥100 1배 **QQQ** 로 봄)로 수량을 모은다
- 전환 기준 ① 나스닥100 이 전고점 대비 15% 하락 ② 내 QQQ 평균 매수가 대비 15% 하락
- 기존 QQQ 는 팔지 않고, **새로 넣는 돈부터 QLD(2배)** 를 산다

## 시험 조건

| 항목 | 값 |
|---|---|
| 돈 | 첫날 원금 P(1만$ · 10만$)를 넣고, 달이 바뀐 첫 거래일마다 P 의 3%(300$ · 3,000$)를 더 넣음 |
| 무엇을 사나 | 넣는 날 **전일 종가**로 정함(룩어헤드 없음). 조건이면 그날 넣은 돈 전부 QLD, 아니면 QQQ. 그날 종가 체결 |
| 지수 기준 | ^NDX 전일 종가 ≤ 그때까지 사상 최고 종가 × 0.85 (자료 1985-10 부터) |
| 평단 기준 | QQQ 전일 종가 ≤ 내 QQQ 평단(수수료 포함) × 0.85 |
| 매도 | 없음(화면 그대로). 확장 'back' 만 회복 때 QLD → QQQ (화면에 없는 규칙 · 실험) |
| 비용 | 수수료 0.1% · 끝날 전부 판다고 보고 양도세 22%(연 250만원 공제 = 1,852$) 뺀 **세후** |
| 주수 | 정수 주(실제 거래 단위 가격 = 조정종가 × 이후 액면분할 배수) · 남은 돈은 다음 달로 |
| 자료 | QQQ·QLD 조정종가(배당 재투자) · QQQ 상장(1999-03-10) 전은 NDX + 연 0.09% · QLD 상장(2006-06-21) 전은 `2 × QQQ 일수익 − (1.58% + T-bill)/252` |
| 합성 검증 | 2006~2026 해마다 실제 QLD 와 차이 −1.2 ~ +1.0%p (`node series.js`) |
| 엔진 검산 | 소수 주로 끝 값을 따로 셈 → 12개 경우 모두 0.0000% 차이 |

## 판단

1. **수익은 대부분 '2배 레버리지' 덕이다.** 지수 기준 결과는 QLD 만 적립과 거의 같고, 타이밍 없이 같은 비율로 섞은 것보다 10년 중앙값으로 연 1~2%p 낫다(타이밍 효과).
2. **'위험 관리' 는 되지 않는다.** QLD 를 팔지 않으니 오를수록 QLD 비중이 커져 끝에는 90% 넘게 QLD 가 된다. 넣은 돈 대비 최악 −88.5%(QQQ 만 −67.4%).
3. 2009 년 뒤 강세장이 결과를 만든다. 1999~2002 년에 시작한 10년은 QQQ 만보다 연 2~8%p 졌다.
4. 평단 기준은 시작 시점 운이다 — 오래 모은 사람은 평단이 낮아 거의 안 켜진다(1986 시작 40년 0번 · 2006 시작은 2008-11~2009-05 일곱 달).
5. 확장 'back'(회복 때 QLD → QQQ · 화면에 없음)은 2006~ 세후 +268% → +54%, 최악 낙폭은 같았다(낙폭이 회복 전에 나옴).
6. 2026-11-10 기준 나스닥100 은 전고점(2026-10-06 · 31,224) 대비 −11.2%. 26,541 아래로 닫히면 켜진다(11-05 에 −14.7%).
