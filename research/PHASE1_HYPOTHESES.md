# Phase 1 — 가설 설계

승인받은 Phase 0 결정: ① 분봉 가설도 **정식 판정** 대상에 넣되 표본 한계를 판정문에 명시하고
**전진 수집도 동시에 시작** ② 관리·경고종목은 **대용 필터로 근사** ③ 유니버스 **전체 수집**

## 0. 출발점에서 정직하게 밝힐 것

이 저장소는 이미 35개 절에 걸쳐 국내 단타 가설을 검증했고, **거의 전부 폐기됐다.**
아래 가설들은 그 결과와 무관하게 새로 세운 것이 아니라, **다음 세 가지가 달라졌기 때문에
다시 볼 가치가 있는 것들**이다.

| 이전 검증 | 이번 |
|---|---|
| 197종목 (오늘 시점 거래대금 상위 = **생존편향**) | **2,773종목 · 상폐 218종목 포함** |
| 마찰 0.5% 단일 가정 | **호가단위 기반 · 세율 0.20% · 1x/2x/3x** |
| 거래·날짜 단위 혼용 | 자리(slot) 포트폴리오 · 고정 2,000만 비복리 |

**사전 등록**: 아래 5개 가설과 파라미터 범위를 지금 고정한다. Phase 3 전에 추가하지 않는다.
추가하게 되면 다중검정 보정 K에 반영하고 experiments.csv 에 남긴다.

**공통 규칙 (전 가설)**
- 진입: **09:00 시가**. 판단에 쓰는 정보는 **전일 종가까지**만. 당일 OHLC 사용 시 look-ahead.
- 청산: **당일 종가** (H4만 예외). 오버나잇 없음.
- 유니버스 대용 필터(②의 결정): 전일 종가 ≥ 1,000원, 전일 거래대금 ≥ 5억,
  20일 실현변동성 상위 1% 제외, `halt` 플래그(OHLC=0) 행 제외, 상장 60일 미만 제외
- 상한가 시가는 매수 불가, 하한가는 매도 불가로 처리
- 자리 3개 · 종목당 1/3 · 원금 2,000만 고정

## H1. 갭 크기별 — 추종인가 되돌림인가

**경제적 근거**. 개장 갭에는 두 성분이 섞여 있다. 밤사이 들어온 **진짜 정보**와,
동시호가에 몰린 주문이 만든 **과잉반응**. 정보분은 장중에도 같은 방향으로 이어지고(추종),
과잉반응분은 되돌린다(갭 메우기). **갭 크기가 그 비율을 가른다**는 것이 가설이다.
작은 갭은 대부분 잡음(되돌림 우세), 큰 갭은 정보(추종 우세) — 또는 그 반대일 수도 있다.
**방향을 미리 정하지 않고 구간별로 측정한다.**

**규칙**
```
g = (시가 − 전일종가) / 전일종가 × 100
g ∈ [a, b] 이고 유니버스 필터 통과 → 09:00 시가 매수, 당일 종가 매도
같은 구간에 종목이 많으면 전일 거래대금 상위 3개
```

**자유 파라미터 (3개)**: 구간 하한 `a`, 구간 상한 `b`, 전일 거래대금 하한 `minTurnover`
구간 격자는 미리 고정: `(-∞,-10] (-10,-5] (-5,-2] (-2,0] (0,2] (2,5] (5,10] (10,∞)`

**예상 실패 원인**
- 13절에서 장중(시가→종가)은 −0.076%/일이었다. 비용 0.43% 문턱을 넘을 신호가 없을 가능성이 가장 크다.
- 큰 갭 구간은 표본이 얇고 특정 연도(2020, 2022)에 몰릴 것이다.
- 갭 상위 구간은 상한가 근처라 **시가 매수가 체결되지 않는다**(32절의 역선택과 같은 함정).

## H2. 전일 관심 급증 종목의 다음날 장중

**경제적 근거**. 전일 거래량이 폭증한 종목은 다음날도 관심이 남는다(모멘텀)거나,
전일 들어온 단기 자금이 빠져나간다(소진). 32절에서 **밤사이 갭**은 거래량 배수에 단조 증가했지만
**그 종목을 전일 종가에 살 수 없었다**(매도 물량 없음). **시가에는 살 수 있다** — 동시호가는
양방향 주문이 모이므로 역선택이 훨씬 약하다. 그래서 같은 신호를 **시가→종가 구간**에서 다시 본다.

**규칙**
```
전일 거래량 / 직전 20일 평균거래량 ≥ k
전일 등락률 ≥ m%
→ 09:00 시가 매수, 당일 종가 매도 (거래대금 상위 3개)
```

**자유 파라미터 (3개)**: `k` ∈ {2,3,5,10}, `m` ∈ {0, 3, 5, 10}, `minTurnover`

**예상 실패 원인**
- 이 저장소에서 "뜨거운 것을 쫓는" 신호는 예외 없이 마이너스였다(16·18·25절).
- 전일 급등 종목은 다음날 변동성이 커서 **틱 슬리피지가 크다**. 저가주면 왕복 0.73%.
- 상한가 다음날은 시가 매수 자체가 어렵다.

## H3. 갭하락 + 과매도의 장중 반등 (유동성 공급)

**경제적 근거**. 이게 다섯 중 **사전 확률이 가장 높은 가설**이다.
33절에서 SPY 시가 −3% 지정가 → 종가 청산이 t=3.41 로 나왔고, 정체는 "위기 때 유동성 공급"이었다.
31절에서 S&P500 과매도(RSI<35) 반등은 33년 3등분 전부 플러스로 **유일하게 편향 검사를 통과**했다.
**국내 개별주에서, 상폐 포함 전종목으로, 비용을 제대로 물려서** 같은 것이 남는지 본다.
국내는 33·31절에서 지수로는 부호가 반대였지만 **개별주 횡단면은 본 적이 없다.**

**규칙**
```
전일까지의 RSI(14) ≤ r
갭 g ≤ −x%
→ 09:00 시가 매수, 당일 종가 매도 (갭이 깊은 순 3개)
```

**자유 파라미터 (3개)**: `r` ∈ {30,35,40}, `x` ∈ {0,1,2,3,5}, `minTurnover`

**예상 실패 원인**
- 33절에서 고정 퍼센트 임계값은 **몰래 국면을 고른다**. 파라미터를 ATR 배수로도 돌려 교차 확인해야 한다.
- 갭하락 종목에는 **악재 공시·유상증자·관리종목 지정**이 섞인다. ②의 대용 필터로 다 못 거른다.
- 되돌림이 있어도 0.43~0.73% 를 넘지 못할 가능성.

## H4. 시초 N분 고가 돌파 (ORB) — **분봉, 표본 1년**

**경제적 근거**. 개장 직후 변동성이 해소되고 방향이 확정되면 그 방향이 이어진다는 고전 가설.
13절에서 이미 폐기됐지만, 그때는 **197종목 생존편향 유니버스 · 마찰 0.5% 단일 가정**이었다.
이번엔 유니버스와 비용 모델이 다르다.

**규칙**
```
09:00~09:N 의 고가를 상향 돌파하는 첫 1분봉의 종가에 매수
청산: 당일 종가 (분봉이 9:30까지뿐이면 09:30 종가로 대체 — 보고에 명시)
```

**자유 파라미터 (3개)**: `N` ∈ {5,10,15}, 돌파 확인폭(틱), `minTurnover`

**예상 실패 원인**
- **표본이 243거래일뿐이다.** IS/OOS로 쪼개면 각 6개월 — 폐기 기준 "OOS가 IS의 절반 미만"을
  적용하기엔 검정력이 낮다. **이 한계를 판정문에 반드시 쓴다.**
- **NXT 출범 전 구간이 아예 없다**(분봉이 2025-09부터). 요구하신 전/후 분리가 불가능하다.
- 보유 분봉이 **9:00~9:30 만**이라 종가 청산을 쓰려면 새로 수집해야 한다.
- 13절 결과가 이미 강하게 부정적이다.

## H5. 저유동성 소형주의 시가 효과

**경제적 근거**. 이 저장소에서 **모든 편향 검사를 통과한 것은 22절 비유동성 하나뿐**이었다
(거래대금 하위 10종목 20일 보유). 기관이 규모 때문에 못 들어오는 자리라 개인에게 남는다는
문헌의 설명과도 맞는다. **그 효과가 일 단위(시가→종가)에도 있는지**는 본 적이 없다.
그리고 이번엔 **상폐 종목이 포함**돼 있어 — 저유동성 구간은 상폐 편향이 가장 심한 곳이다 —
비로소 정직하게 잴 수 있다.

**규칙**
```
유니버스 필터 통과 종목을 전일 거래대금으로 정렬, 하위 q 분위
그중 갭 g ≤ 0 인 종목 3개 (거래대금 낮은 순)
→ 09:00 시가 매수, 당일 종가 매도
```

**자유 파라미터 (3개)**: 분위 `q` ∈ {10%, 20%, 30%}, 갭 상한, `minTurnover`(하한은 유지)

**예상 실패 원인**
- **비용이 가장 큰 구간이다.** 저가주 틱 슬리피지만 왕복 0.5%, 총 0.73%.
- **유동성 제약**에 실제로 걸린다 — 주문금액 ≤ 시가 체결대금 1% 룰을 시가 체결량 없이
  전일 거래대금으로 대체해야 해서, 이 가설은 대체 지표에 가장 민감하다.
- 상폐 편향을 제거하면 22절 결과 자체가 약해질 수 있다(22절은 생존편향 유니버스였다).

## 판정 순서

1. **Phase 2 먼저**: 무작위 진입이 정확히 `−비용` 수준으로 나오는지 확인한다.
   여기서 0 이 아닌 값이 나오면 엔진에 버그가 있는 것이다. **이게 통과하기 전엔 어떤 결과도 믿지 않는다.**
2. IS(2018-06 ~ 2024-12)에서만 파라미터를 본다. OOS(2025-01 ~ 2026-09)는 **최종 판정 직전까지 열지 않는다.**
3. 5개 가설 × 파라미터 격자 전부를 experiments.csv 에 남긴다. 선별 기록 금지.
4. 다중검정 보정 K = 실제로 돌린 조합 수.

## 사전 예상 (기록용)

정직하게 적어둔다: **다섯 개 모두 폐기될 가능성이 높다고 본다.**
H3 > H5 > H1 > H2 > H4 순으로 사전 확률을 둔다. 결과가 이 순서와 다르게 나오면
**그 자체를 버그 신호로 의심**한다.
