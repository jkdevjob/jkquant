개인정보처리방침

시행일: 2026년 10월 30일

1. 이 앱이 하는 일

"은퇴노트" 앱은 은퇴노트 채널 운영자가 직접 만든 영상을 운영자 본인의 유튜브 채널과 인스타그램 계정(@retire.note)에 올리기 위해서만 사용하는 개인용 도구입니다. 다른 사람이 로그인하거나 사용하는 서비스가 아닙니다.

2. 사용하는 정보

  • 운영자 본인 계정의 접근 권한(유튜브 동영상 업로드, 업로드 목록 조회 / 인스타그램 게시물 게시·조회)
  • 업로드 목록 조회는 같은 영상을 두 번 올리지 않도록 최근 업로드 제목을 확인하는 데만 씁니다.

시청자나 다른 사용자의 개인정보는 수집·저장·공유하지 않습니다.

3. 보관

접근 토큰은 운영자만 쓸 수 있는 비공개 실행 환경의 설정값으로만 보관하며, 공개 저장소나 다른 곳에 저장하지 않습니다. 운영자는 구글 계정 설정(보안 → 타사 액세스)과 메타 앱 설정에서 언제든 권한을 철회할 수 있습니다.

4. 구글 사용자 데이터

이 앱의 구글 API 사용은 Google API Services 사용자 데이터 정책을 따릅니다. YouTube API를 사용하며 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
