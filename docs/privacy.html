개인정보처리방침

시행일: 2026년 10월 30일 · 개정: 2026년 11월 13일

1. 이 앱이 하는 일

"은퇴노트" 앱은 은퇴노트 채널 운영자가 직접 만든 영상을 운영자 본인의 유튜브 채널과 인스타그램 계정(@retire.note)에 올리기 위해서만 사용하는 개인용 도구입니다. 다른 사람이 로그인하거나 사용하는 서비스가 아닙니다.

2. 사용하는 정보

  • 운영자 본인 계정의 접근 권한(유튜브 동영상 업로드, 업로드 목록 조회 / 인스타그램 게시물 게시·조회)
  • 업로드 목록 조회는 같은 영상을 두 번 올리지 않도록 최근 업로드 제목을 확인하는 데만 씁니다.

시청자나 다른 사용자의 개인정보는 수집·저장·공유하지 않습니다.

3. 보관

접근 토큰은 운영자만 쓸 수 있는 비공개 실행 환경의 설정값으로만 보관하며, 공개 저장소나 다른 곳에 저장하지 않습니다. 운영자는 구글 계정 설정(보안 → 타사 액세스)과 메타 앱 설정에서 언제든 권한을 철회할 수 있습니다.

4. 구글 사용자 데이터

이 앱의 구글 API 사용은 Google API Services 사용자 데이터 정책을 따릅니다. YouTube API를 사용하며 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

5. 데이터 삭제와 권한 철회

  • 시청자나 다른 사용자의 데이터는 처음부터 저장하지 않습니다.
  • 저장하는 것은 운영자 본인 게시물의 ID·링크 기록과 접근 토큰뿐이며, 권한을 철회하거나 삭제 요청이 있으면 30일 안에(보통 즉시) 삭제합니다.
  • 구글 권한은 Google 보안 설정 → 타사 액세스에서 언제든 철회할 수 있습니다.

Privacy Policy (English)

Effective: October 30, 2026 · Updated: November 13, 2026

What this app does. "Retire Note Uploader" is a private tool used only by the owner of the 은퇴노트 (Retire Note) channel to upload the owner's own videos to the owner's own YouTube channel and Instagram account (@retire.note). No other person signs in or uses it.

Data used. Access to the owner's own accounts only: YouTube video upload and reading the owner's own recent uploads (used only to avoid uploading the same video twice); Instagram post publishing and reading the owner's own recent posts. We do not collect, store, or share personal data of viewers or any other users.

Storage. Access tokens are stored only as encrypted private secrets in the owner's GitHub Actions environment, never in public files. We keep only the IDs/links of our own published posts in a private log. The owner can revoke access at any time at Google Account → Third-party access and in the Meta app settings.

Google user data. Our use of Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; the YouTube Terms of Service and the Google Privacy Policy apply.

Data deletion and revocation. We never store viewer or third-party data. The only stored items are the IDs/links of our own posts and the access tokens; they are deleted within 30 days (usually immediately) when access is revoked or deletion is requested. Google access can be revoked at any time at the Google security settings page.

Contact. Instagram direct message to @retire.note.
