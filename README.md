# jkquant

## 배포 버전 규칙

배포할 때는 반드시 화면에 표시되는 앱 버전도 함께 올린다. 코드만 배포하고 버전을 그대로 두는 배포는 금지한다.

- **메이저 변경**: 정수 자리를 올리고 소수 자리는 0으로 초기화한다. 예: `v5.6 → v6.0`
- **마이너 변경**: 소수점 한 자리를 올린다. 예: `v5.6 → v5.7`
- 버전 변경은 실제 배포 커밋/PR에 포함한다.
- 운영 화면·백테스트 등 동일 제품에서 노출되는 버전 표기는 서로 어긋나지 않도록 함께 확인한다.
- 배포 전 회귀검사 ALL PASS를 확인한 뒤 버전이 실제 화면에 반영됐는지 확인한다.
