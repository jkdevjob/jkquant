## 새 Work/개발 세션 시작 요청문

> JKQuant의 최신 main SHA를 먼저 확인하고, `REQUIREMENTS.md`와 `TASKS.md`, `CHANGELOG.md`, `TEST_RESULTS.md`, `CLAUDE.md` 및 해당 소스를 비교해 줘. 현재 문제가 재현된 경우 우선순위 높은 항목부터 실제로 수정하고, 관련 테스트와 전체 CI를 확인한 뒤 병합·배포·운영 확인까지 진행해. 끝난 것과 실패·미검증을 구별해 작업 문서를 갱신하고, 기존 운영 전략·사용자 장부·명시적 설정은 허가 없이 변경하지 마.

**참고:** 이 네 문서는 대화 기억의 대체물이 아니라 검증 가능한 저장소 작업 이력이다. 최신 저장소 코드와 실제 실행환경에 맞춰 계속 갱신한다.
