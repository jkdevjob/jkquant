# 일일 경제 핫이슈 블로그 작성 규칙

매일 아침 한 편. 예약 작업이 이 문서를 읽고 그대로 따른다.
기준 예시: `2026-10-26_oil-rate.md`

## 1. 주제 고르기

- **전날 가장 이슈였던 경제·시장 뉴스 하나**를 다룬다.
  '전날'은 한국 시간 어제 하루와 간밤 미국·유럽 시장 마감까지다(실행 시점 기준 지난 24시간).
  국내(증시·환율·금리·부동산·정책)와 해외(연준·유가·빅테크·지정학) 모두 후보.
- '가장 이슈'는 실제로 확인할 수 있는 근거로 고른다:
  여러 주요 매체가 같은 날 머리기사로 다뤘는지, 증시·환율·금리·유가가 크게 움직였는지,
  정부·중앙은행의 공식 발표인지. 검색량·조회수 순위는 실제 자료 없이 지어내지 않는다.
- **지난 7일 안에 다룬 주제는 피한다.** `blog/` 의 파일 이름과 제목을 먼저 확인한다.
  전날 가장 큰 이슈가 이미 다룬 주제라도 큰 진전(예: FOMC 결과 발표)이면 "후속편"으로 다루고,
  진전이 없으면 전날 두 번째로 큰 이슈를 고른다.
- "원리부터 쌓아 올려 전날 뉴스로 연결"할 수 있게 쓴다
  (단순 시세 나열·속보 요약은 피한다).
- 다루지 않는 것: 개별 종목 매수·매도 추천, 확인 안 된 루머가 핵심인 이슈,
  Anthropic(작성 도구 제공사) 관련 이슈(이해충돌).

## 2. 조사

- 서로 다른 출처 **3곳 이상**에서 사실을 확인한다. 기사 원문을 열어 숫자를 직접 확인한다.
- 숫자마다 날짜를 붙인다(언제 기준인지). 출처끼리 수치가 다르면 범위로 쓰거나 "보도마다 차이" 표시.
- 확인 안 된 내용은 "~라는 보도가 나옴"처럼 보도임을 밝힌다. 인용문을 지어내지 않는다.
- 다른 블로그(메르 블로그 포함)의 문장을 옮기지 않는다. 형식만 따르고 문장은 새로 쓴다.

## 3. 형식

- **제목**: 클릭하고 싶게, 그러나 본문이 증명하는 만큼만 세게. 30~45자.
  - 쓰는 장치(2개 이상 섞는다):
    - 눈에 박히는 구체 숫자를 앞에: "반대표 2장", "117달러", "하루 3%"
    - 반전·대비: "동결했는데 왜 긴축?", "수출은 사상 최대인데 왜 불안?"
    - 독자 지갑과 연결: "내 예금 이자", "연금 계좌", "대출 금리"
    - 궁금증을 남기는 질문형 끝맺음: "~하는 진짜 이유", "~가 의미하는 것"
  - 예) 밋밋함 "연준이 금리를 동결했는데, 왜 '긴축은 안 끝났다'는 말이 나올까?"
    → 어그로 "금리 동결인데 반대표 2장… 연준이 '12월 인상' 문을 열어둔 이유"
  - 금지: 본문이 뒷받침 못 하는 과장(폭락·대참사·역대급을 사실 없이), 가짜 긴급성
    ("지금 당장 팔아라"), 종목 매수·매도 지시, 제목의 질문에 본문이 답하지 않는 낚시,
    따옴표 안에 실제로 하지 않은 말 넣기. '숨긴'·'진짜 이유' 같은 표현은 본문에서
    그 근거(발언·수치)를 분명히 보여줄 때만 쓴다.
- **도입**: 한 줄. 예) "어제 ○○ 소식이 하루 종일 시장을 흔들어서 정리해 봅니다."
- **본문**: 번호를 붙인 짧은 문장 60~80개. 끝맺음은 "~임 / ~함 / ~됨 / ~있음".
  - 한 문장에 사실 하나.
  - 기초 개념(용어 뜻, 구조) → 배경(지난 흐름) → 전날 사건 → 파급 경로 → 한국 영향 순서.
  - 일상 비유 2~3개(쌀, 깔때기, 택배처럼 누구나 아는 것).
  - "지금까지 흐름을 따라왔으면 ○일 보도를 이해할 수 있을 것임" 같은 연결 문장을 한 번 넣는다.
  - 끝부분에 노후·연금·가계 자산 관점 2~3문장(은퇴노트 독자용). 투자 권유는 하지 않는다.
- **마무리**: `한줄 코멘트.` 로 시작하는 3~4문장 요약 + 앞으로 볼 일정(지표 발표·회의 날짜).
- **면책**: `※ 정보 제공 목적의 글이며 투자 권유가 아닙니다.`
- **분량**: 본문 3,500~4,500자(공백 포함).
- 사진 자리(`[사진: …]`)는 넣지 않는다(블로거 자동 게시에는 사진 단계가 없다).

## 4. 파일

- 경로: `blog/YYYY-MM-DD_<영문-짧은-이름>.md` (예: `2026-10-28_fomc-hold.md`)
- 1행: `# 제목`
- 2행: `<!-- labels: 키워드1, 키워드2, 키워드3 -->` (블로거 라벨, 3~5개)
- 본문 → 한줄 코멘트 → 면책 → `---` → `출처` → 출처 목록
- 출처 목록은 링크 형식: `- [매체, 「기사 제목」(날짜)](https://주소)`

## 5. 게시

```
node blog/publish-blogger.mjs blog/<파일>.md
```

- 필요한 환경변수: `GOOGLE_CLIENT_ID` `GOOGLE_CLIENT_SECRET` `GOOGLE_REFRESH_TOKEN` `BLOGGER_BLOG_ID`
- 없으면 게시를 건너뛰고 "키 미설정"으로 보고한다(글 파일은 저장·커밋).
- 이미 게시한 파일은 `blog/published.json` 에 남아 다시 올라가지 않는다.
