# 네이버 블로그(maniacjk) 발행 스크립트

블로거 글과 같은 주제로 네이버용 글을 따로 써서 올릴 때 쓴다(매일 07:35 예약).
네이버 약관은 자동화 수단으로 로그인·게시하는 것을 금지한다. 사용자가 이 위험을 안내받고
직접 결정했다(2026-10-30). 공식 글쓰기 API는 없다.

## 원고 형식 (`post.json`)

```json
{
  "title": "제목(30~45자)",
  "blocks": [
    {"t": "p", "text": "도입 한 문단(번호 없음)"},
    {"t": "img", "file": "그림.jpg", "cap": "캡션 한 줄",
     "attr": ["사진: 저작자 / 출처: <a href=\"원본\">원본</a>", "라이선스: … (<a href=\"…\">…</a>) · 수정 여부"]},
    {"t": "p", "text": "1. 소제목\n본문 한 문단"}
  ],
  "tags": ["태그1", "태그2"]
}
```

- 이미지 블록 다음 줄(`attr`)은 본문에 13px 회색 문단으로 들어가고, 링크가 살아 있다.
- 지난 원고는 `posts/` 에 날짜별로 남긴다.

## 실행 순서

스크립트는 작업용 임시 폴더에서 `node /home/user/jkquant/blog/naver/<스크립트>` 로 실행한다.
스크린샷 같은 산출물은 실행한 폴더에 생기며, 저장소에 넣지 않는다.

1. 브라우저 띄우기(백그라운드)
   `chrome --headless=new --no-sandbox --remote-debugging-port=9222 --user-data-dir=<임시폴더> --proxy-server=$HTTPS_PROXY about:blank`
   스크립트는 모두 `connectOverCDP` 로 붙는다. 브라우저를 끄면 세션 쿠키가 사라진다.
2. 로그인(사용자 입력이 필요하다)
   - QR: `qr_open.js` 를 실행해 `qr_full.png` 를 잘라 사용자에게 보낸다. 유효 시간은 약 3분이다.
     이어서 `qr_wait.js` 가 `LOGGED_IN` 을 찍을 때까지 기다린다.
   - 일회용 번호: `cdp_login.js <8자리>`. 네이버가 이 방식을 '종료 예정'이라고 안내하고 있다.
3. `open_editor.js` 로 빈 편집기를 연다.
4. `fill_post.js <post.json> <이미지폴더>` 로 채운다. 중간에 멈추면
   `fill_post.js <post.json> <이미지폴더> <블록번호> [attronly]` 로 이어서 채운다.
   빠진 묶음은 `insert_section.js <post.json> <컴포넌트번호> <시작블록> <끝블록>` 으로 넣는다.
5. `verify_fill.js <post.json>` 결과가 `mismatch 0`, 캡션은 모두 true, 이미지 수가 맞아야 다음 단계로 간다.
6. `publish_post.js <post.json>` 로 설정을 확인하고 발행 전에 멈춘다. 이어서 `--go` 로 발행한다.
   설정은 카테고리 '경제'(10/31부터 블로그 카테고리가 '경제' 하나로 정리됨; '핫이슈 분석'이 생기면 그것), 비즈니스·경제, 전체공개, 댓글·공감·검색 허용, 공지 OFF, 기본값 유지 OFF다.
7. `verify_post.js <logNo>` 와 `verify_imgs.js <logNo>` 로 로그인하지 않은 화면에서 확인한다.
8. 브라우저를 끄고 임시 프로필 폴더를 지운다(`pkill` 패턴이 자기 셸과 겹치지 않게 PID로 끈다).

## 알려진 함정

- 붙여넣기를 연달아 하면 편집기가 앞의 입력을 놓칠 수 있다. `fill_post.js` 는 문단 수가
  늘었는지 확인하고, 늘지 않으면 실패로 멈춘다.
- 캡션 칸에서 Enter 를 누르면 커서가 본문으로 나간다. 캡션은 한 줄로만 쓴다.
- 제목 칸의 '제목'은 안내 문구라서, 비었는지는 `.se-placeholder` 를 빼고 판단한다.
- 첫 글이면 네이버가 '#첫글' 태그를 자동으로 넣는다. `publish_post.js` 가 관련 없는 태그를 지운다.
- 위키미디어 이미지 서버는 자동 접근을 자주 429로 막는다. 막히면 우회하지 말고,
  이미 라이선스를 확인한 이미지나 직접 그린 도표를 쓴다.
