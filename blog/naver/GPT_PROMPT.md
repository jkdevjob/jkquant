# GPT용 매일 네이버 글 프롬프트 (2026-11-04)

사용자가 GPT에게 클로드와 같은 방식(원고 작성 → 로그인 링크 → 사용자가 QR 로그인 → 직접 발행)을 시키려고 요청한 문안.

```
[매일 아침 네이버 블로그 글 1개 — 작성 → 로그인 링크 → 직접 발행]
보고는 한국어로만 한다. 드라이브 업로더용 .naverpack.zip 은 더 만들지 않는다(업로더가 잘 돌지 않아 중단).

1) 대상: 네이버 블로그 maniacjk(https://blog.naver.com/maniacjk). 하루 1개. 클로드도 매일 1개를 따로 올린다.

2) 주제: 전날(한국 시간 어제 하루 + 간밤 미국·유럽 시장 마감) 가장 이슈였던 경제·시장 뉴스 하나.
   먼저 글 목록을 열어 지난 7일 글, 같은 날 이미 올라온 글(클로드 글 포함)과 겹치지 않는 주제를 고른다.
   목록: https://blog.naver.com/PostTitleListAsync.naver?blogId=maniacjk&currentPage=1&categoryNo=0&countPerPage=30
   겹치면 큰 진전이 있을 때만 후속편, 아니면 두 번째 이슈를 쓴다.

3) 사실 확인: 숫자·인용은 서로 다른 출처 3곳 이상의 원문에서 확인한다. 확인 못 한 숫자·인용은 넣지 않는다.
   보도마다 다르면 범위로 쓰거나 '보도마다 차이'를 밝힌다. 해석·전망 문단은 (해석)·(전망)으로 표시한다.
   종목 매매 추천은 하지 않는다. 제목은 클릭하고 싶게 쓰되 본문이 뒷받침하지 못하는 과장·낚시는 쓰지 않는다.

4) 형식:
   - 제목 30~45자. 본문 1,800~2,500자(문단 글자 합).
   - 쉬운 도입 한 문단(번호 없음) + 번호 문단 8~15개("1. 소제목" 다음 줄에 본문).
     흐름: 이슈 → 배경 → 원인 → 영향 → 반대 시나리오·앞으로 확인할 지표.
   - 비유 2~3개. 50~60대 독자도 읽기 쉬운 말로 쓴다.
   - 이미지 2~3개. 직접 그린 도표가 기본이다(가로 막대 등, 단위·기준 시점 표시). 도표의 숫자는 본문에도 있어야 한다.
     이미지마다 한 줄 캡션, 바로 아래 회색 작은 글씨로 "사진: 블로그 직접 작성 도표 / 출처: <링크>"를 넣는다.
     남의 사진은 라이선스를 확인한 것만 쓴다.
   - 본문 문단에는 링크·HTML 을 넣지 않는다(출처 링크는 이미지 아래 줄에만).
   - 태그 5~8개(# · 공백 없이).

5) 로그인(사용자 지시: "블로그 글 생성하고 링크를 줘 내가 로그인 할테니까"):
   - 비밀번호는 절대 묻거나 받지 않는다. 일회용 번호 로그인은 네이버가 '종료 예정'이라 2026-11-04 에 거절됐다. QR 로그인을 쓴다.
   - 원고가 다 되면 네가 쓰는 브라우저에서 아래 QR 로그인 화면을 연다.
     https://nid.naver.com/nidlogin.login?mode=qrcode&url=https%3A%2F%2Fblog.naver.com%2FMyBlog.naver&locale=ko_KR&svctype=1
   - 사용자는 폰 하나로 작업해서 화면의 QR 을 찍을 수 없다. 그래서 세 가지를 같이 보낸다.
     ① QR 안의 로그인 주소(https://nid.naver.com/nidlogin.qrcode?mode=qrcode&qrcodesession=… 형태, QR 을 해독해서 얻는다)
     ② 화면에 보이는 고를 숫자
     ③ QR 이미지(사진에 저장 → 네이버 앱 렌즈 → 앨범으로 불러오는 대체 방법)
   - QR 은 약 3분이면 만료된다. 만료되면 새 QR 을 띄워 다시 보낸다.
   - 브라우저를 사용자에게 직접 넘겨줄 수 있는 환경이면 그 방식으로 로그인 화면을 넘겨도 된다.

6) 발행: 로그인되면 글쓰기 화면에서 제목·본문·이미지·캡션·출처 줄·태그를 넣고 아래 설정으로 발행한다.
   카테고리 '경제', 주제 '비즈니스·경제', 전체공개, 댓글·공감·검색 허용, 공지 끔, '기본값으로 유지' 끔.
   '작성 중인 글이 있습니다' 창이 뜨면 새로 작성한다. 블로그의 다른 설정이나 지난 글은 건드리지 않는다.

7) 확인: 로그인하지 않은 화면에서 새 글 주소를 열어 제목·이미지 수·캡션·출처 링크를 확인하고, 글 목록 맨 위에 있는지 본다.
   두 가지를 직접 확인한 뒤에만 '네이버 발행 완료'라고 한다. 실패하면 화면의 오류 문구를 그대로 알린다.

8) 보고: 제목 / 고른 이슈와 근거 한 줄 / 글 주소 / 문단·이미지·태그 수 / 주요 출처 3곳 / 확인 결과.
```
